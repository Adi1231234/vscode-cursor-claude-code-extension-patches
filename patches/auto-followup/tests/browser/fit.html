does the dialog fit

The dialog is position:fixed, so it is laid out against the viewport - and an iframe has a viewport of whatever size it is given. That is the whole trick here: no emulation, no CDP, no editor. Every row is a real layout at a real size, with the panel's own zoom applied the way patches/zoom applies it.

A row fails if any edge of the dialog leaves the viewport, if the header or the footer cannot be reached, or if the body collapses to nothing.
